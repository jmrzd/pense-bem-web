# 🤝 Responsabilidade compartilhada

Embora cada integrante possua uma área principal, o projeto será desenvolvido de forma colaborativa.

A equipe trabalhará em conjunto nas etapas de:

- integração;
- revisão de código;
- testes;
- resolução de bugs;
- documentação;
- deploy;
- apresentação acadêmica.
